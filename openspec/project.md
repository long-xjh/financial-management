# 项目上下文（Project Context）

## 项目说明

个人理财投资管理仓库：登记真实持仓（黄金基金、其他基金、股票/ETF 等）与定投计划，以文档形式制定投资计划，借助 AI 获取标的最新行情，通过定时任务自动分析行情并给出计划调整建议。

## 技术选型

- **数据层**：Markdown 文档（`portfolio/`、`plans/`、`analysis/`、`journal/`），人可读、AI 可解析、git 可版本化，不引入数据库。
- **工具层**：Python 脚本（`scripts/`）负责行情抓取，候选数据源：akshare、东方财富/天天基金公开接口。
- **自动化层**：ZCode 定时任务（Automations）或系统 cron，定时触发 AI/脚本生成分析报告。
- **规格层**：OpenSpec 管理能力规格与变更提案。

## 当前状态

- 2026-10-27：完成仓库初始化（目录骨架、模板、AI 协作规范、子代理）。
- 尚未登记真实持仓；行情抓取脚本与定时任务待建设（走 changes 提案）。

## 约束

- 单人使用，无服务端、无数据库，保持轻量。
- 数据敏感：仅使用私有远端，不对外公开。
- 中文优先。
